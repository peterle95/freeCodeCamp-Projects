# Music Player Project

A web-based music player built with HTML, CSS, and JavaScript as part of the freeCodeCamp curriculum.

## About

This project is part of the **freeCodeCamp** JavaScript Algorithms and Data Structures certification. It demonstrates the implementation of a functional music player using vanilla web technologies.

## Features

- Play/pause functionality
- Next/previous song navigation
- Audio playback controls
- Dynamic song information display
- Responsive design

## Technologies Used

- **HTML** - Structure and markup
- **CSS** - Styling and layout
- **JavaScript** - Interactive functionality and audio controls

## Getting Started

1. Clone or download this repository
2. Open `index.html` in your web browser
3. Use the controls to play, pause, and navigate through songs
